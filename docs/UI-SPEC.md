# 赶词工 · UI 规范 v0.1

技术：Naive UI（表格/表单/弹窗/消息）+ Tailwind v4（布局、间距、卡片定制）。图标 `@vicons/ionicons5`。

## 1. 设计基调

「工具感、克制、有点压迫但不脏」。复习弹窗是主角，管理页是配角。避免默认组件库的通用感：卡片不用默认阴影，改用 1px 描边 + 极小圆角；主操作按钮只有一种颜色。

## 2. 设计 token

| token | 值 | 用途 |
|---|---|---|
| `--brand` | `#1F7A5C` | 主操作、进度、选中 |
| `--brand-press` | `#175F48` | hover/active |
| `--accent` | `#E86A2C` | 倒计时、额度告警、强制模式标识 |
| `--danger` | `#C93B3B` | 不认识、Kiosk 警告 |
| `--ink` | `#15201C` | 主文字 |
| `--muted` | `#6B7A74` | 次文字 |
| `--line` | `#DFE5E1` | 描边 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--canvas` | `#F4F6F4` | 窗口背景 |
| `--canvas-dark` | `#121917` | 强制全屏背景（深色，减少环境光干扰） |

- 圆角：卡片 10px、按钮 6px、弹窗 14px
- 间距：4 的倍数栅格；页面外边距 24px；卡片内边距 20px
- 阴影：仅弹窗用 `0 18px 48px rgba(15,32,28,.18)`，页面内卡片不阴影
- 字体：`"Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`（无外链字体，网络受限环境同样可用）；单词大字用 `ui-serif, Georgia` 拉出对比
- 字号：单词卡 64/72px、页面标题 20px、正文 14px、辅助 12px
- 动效：翻卡 180ms `cubic-bezier(.2,.7,.3,1)`；不做页面转场动画

## 3. 主窗口（1200×760，最小 980×640）

左侧 200px 固定导航（复习台 / 词库 / 设置 / 统计），底部放托盘提示与版本号；右侧内容区。

### 复习台（首屏 —— 关键信息与主操作必须在第一屏内，不做等权重卡片平铺）
第一屏自上而下依次：
1. **下一次提醒**：`14:20（3 分钟后）`，大字，`--accent`
2. **今日待复习** 数量 + 已掌握/新词/待补充释义 三个小数字行内排列
3. **延后余量**：`●●○ 剩 2 次`，用尽时整条转 `--danger`
4. 主操作行：「立即开始复习」占 2/3 宽（唯一 `--brand` 实底按钮），右侧「去练习」次级按钮；下方一句「练习是自由打字模式，不计入复习进度」
5. 最近 5 轮记录（时间 / 词数 / 认识率），表格紧凑行
6. 今日 24 小时时段条：横条上标出复习时段区间与已触发点位

### 词库
- 顶部工具行：词表下拉、搜索、`+ 新增单词`、`导入 CSV`、`导出 CSV`
- 表格列：单词 / 音标 / 释义 / 标签 / 下次到期 / 间隔 / 复习次数 / 遗忘次数 / 操作
- 默认排序「下次到期」升序；「待补充释义」行左侧带 `--accent` 竖条
- 抽屉式新增/编辑表单，单词输入失焦时自动查离线词典回填音标与释义（命中显示「来自离线词典」）
- 导入结果弹窗：成功 N / 更新 M / 跳过重复 K / 缺释义 P

### 设置
分组卡片，不用 tab：
- **复习时段**：多行「起始–结束」时间区间，可增删；触发间隔（分钟，1–120）；单次词数（5–30）
- **复习形态**：温和弹窗 / 强制全屏 单选；强制全屏下再选锁定强度 应用级 / Kiosk 级（选 Kiosk 展开确认框，列出会屏蔽的按键与 Ctrl+Alt+Del 无法屏蔽的事实）
- **出题方式**：下拉选择 自动（新词默写、复习后选义）/ 默写 / 看词选义；选择后即时生效，下方给一句对应的行为说明
- **延后策略**：每日额度、每次推迟分钟
- **提醒**：开机自启、TTS 发音、逃生快捷键（只读展示 + 冲突检测）
- **数据**：库文件路径、打开目录按钮、重建索引

### 统计
- 4 个小指标（今日词数 / 今日认识率 / 连续天数 / 总复习轮次）
- 近 14 天柱状（词数叠加认识率折线）
- 高频遗忘词 Top 20（lapses 降序）

### 练习（参考 Qwerty Learner，不计入 SRS）
- 入口：复习台「去练习」按钮；顶部「← 复习台」返回
- 顶部工具行：词表下拉（默认全部）、隐藏单词开关、开始/换一组
- 主区域：居中大字单词（`--font-term`，64px）+ 释义 + 朗读按钮；底部进度条与 `当前 / 总数`
- 键盘直接输入，无需聚焦：正确字母转 `--brand`，打错的字母原地转 `--danger` 并抖动，退格无效
- 一词打完 220ms 后切下一词；若此时继续敲键，立即切词并计入下一词，不丢键
- 底部统计条：时间 / 输入数 / 速度 WPM / 正确数 / 正确率
- 完成页：本轮词数、用时、WPM、正确率，「再练一轮」「返回复习台」；Enter 也可再来一轮
- 一轮随机抽 20 词；仅读取词库，不写复习记录、不影响到期时间
- 「隐藏单词」只显示下划线占位，已输入字母仍正常显示

## 4. 复习窗口

卡片按词的复习次数自动切换题型（由主进程在 `RoundPlan` 里给出 `mode`）：
- `spell`（第一次复习）：只显示中文释义，下面每个字母一条下划线，用户按顺序默写英文。打错时该位下划线和字母变红并震动 360ms，当前位置不推进；拼完自动判定
- `choice`（复习过）：显示英文 + 音标，给 4 个打乱的中文释义选项（含正确答案），点选或按 1–4
- `reveal`（缺释义兜底）：保留翻牌，Space 显示释义

判定规则：spell 全程无错 = 认识；有任何错字、点「想不起来，看答案」、选错释义 = 不认识。判定后立即显示完整释义 + 词形 + 例句，spell 还会补念单词；底部提示「已判定，即将进入下一词」，可点「现在继续」或按 Space/Enter 提前进入，否则 2.8–4 秒后自动进入下一词。

### 温和弹窗 420×300
圆角 14px、白底、1px `--line` 描边、投影；顶部细进度条（`--brand`）；单词 34px；选项两列紧凑排列；判定后释义显示在选项上方，正文可滚动兜底。右上角 × 关闭（= 延后）。
- 单词字号从 40px 降到 34px：420×300 里要同时放下音标、释义、例句和操作区，40px 会把按钮顶出可视区
- 结算页同样自动关闭，但留 3 秒（比全屏的 5 秒短），否则标完最后一个词窗口瞬间消失，用户来不及看认识率

### 强制全屏
`--canvas-dark` 深底，中央 720px 宽内容区：单词 72px、音标 20px `--muted`。顶部条：`强制复习中 · 第 N / M 词` + 锁定级别（`--accent`）。判定后底部为「已判定，即将进入下一词 / 现在继续」；未判定时底部是「想不起来，看答案」与「稍后再说」。
- 进度未满时不出现任何关闭入口
- 额度耗尽时「稍后」按钮不渲染（不是 disabled，避免诱导点击）
- spell 题不播放 TTS，避免直接念出答案
- 结算页：认识率环 + 用时 + 「完成，返回桌面」；5 秒无操作自动关闭
- Kiosk 档在角落常驻一行 12px 灰字 `Ctrl+Alt+Esc 可紧急退出`

## 5. 交互细则

- 键盘优先：spell 直接敲字母、Backspace 退格；choice 按 1–4 选释义；reveal 用 Space 翻面；判定后 Space/Enter 立即进入下一词
- 所有破坏性操作（删词表、清日志、开 Kiosk）走二次确认
- 反馈用 `useMessage`，成功短、失败带原因；不用 `alert`
- 空状态给动作，不给插画：「还没有词表，先导入一份 CSV」+ 按钮
- 加载 > 200ms 显示骨架；导入用真实进度条（按行数）
